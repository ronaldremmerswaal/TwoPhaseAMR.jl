# Historical jump-inference studies

These notes, experiments, and intermediate TSVs document variants that were
removed when the mimetic implementation was reduced to `joint_smoothed` and
`joint_face`. They are retained for provenance. Some scripts use removed
constructor options or internal functions and are not expected to run
against the current package without porting.

For the maintained comparison and reproducible tools, see
[`../README.md`](../README.md). The combined raw data at
[`../instability_accuracy_results_both_mimetic.tsv`](../instability_accuracy_results_both_mimetic.tsv)
supersede the intermediate sweeps here for the three current benchmark
methods.
