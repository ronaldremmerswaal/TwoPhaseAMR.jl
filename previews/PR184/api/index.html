Public API

TwoPhaseAMR — Module

Tree-native block-adaptive finite-volume operators for single-phase and incompressible one- and two-velocity two-phase Navier–Stokes flow.

Compact standard API

Most applications need only this surface:

The remaining exports are supported advanced building blocks for custom operators, low-level stepping, validation, and visualization backends. Their presence does not imply that an introductory application must assemble those layers manually.

Advancing a flow

FlowSimulation(...; force=nothing) stores the optional body-acceleration callback as flow.force. step!(flow, dt; force=flow.force, observer=NoObserver(), tolerance=sqrt(eps(T)), max_cycles=nothing) advances one full step and returns its pressure-projection statistics. It updates time and counters, performs any due mesh adaptation and associated rebuild, records step diagnostics, and emits a :step observer event.

simulate!(flow, final_time; ...) selects and repeats full steps to an absolute end time, emitting :initial, :completed, and :failed lifecycle events as appropriate. Consecutive calls continue from the retained state and, when applicable, the unshortened automatic timestep proposal. A standalone step! emits no run lifecycle events; observers such as Recorder that rely on them should be used with simulate!. By contrast, the field-level step!(velocity, pressure, system, dt, workspace; ...) performs the physical solve without flow-owned time, counters, adaptation, diagnostics, or observer events.

The two-velocity projection is meaningful only for TwoVelocityModel. Surface-tension force selection applies to either velocity model. A liquid/gas velocity tuple is rejected by OneVelocityModel instead of silently changing the formulation.

A nonnegative number is shorthand for the default conservative ghost-fluid choice: surface_tension=0.05 is equivalent to surface_tension=SurfaceTension(0.05; method=CGFM()).

SinglePhase, TwoPhase, SurfaceTension, AdvectionOptions, and NavierStokesOptions validate values at construction, including when fields are supplied positionally. Phase densities must be positive, and phase viscosities must either both be positive or both be zero. InterfaceField validates reconstruction_method as :lhf, :lhf_ghf, or :wy; rasterize and the static figure functions validate phase_rendering as :cell or :plic. Pressure projection's compatibility is a solve-time keyword and accepts :project or :error.

Diagnostics

Built-in diagnostics are KineticEnergy, PotentialEnergy, SurfaceEnergy, TotalEnergy, LinearMomentum, PhaseVolume, PhaseMass, InterfaceMeasure, MaximumVelocity, CFLTimeStep, DivergenceNorm, LeafBlockCount, and CellCount. Add custom reductions with Diagnostic or add_diagnostic!. Sampling schedules are EveryStep, EveryNSteps, and EveryTimeInterval. Use print_simulation_summary for an end-of-run model, mesh, solver, AMR, and diagnostics report.

See Diagnostics for definitions and recording of simulation-owned histories.

Recording, Studio, and static output

register_default_fields! populates a VisualizationFieldRegistry from a flow. Pass a Recorder as observer to simulate!; snapshot_store exposes its owned frames, scheduled keyframes, mirrored diagnostics, and step log. AbstractObserver, StepInfo, and observe! are the extension points for custom observers. See Recording and visualization for schedules, retention, controls, and examples.

Video time is sampled linearly in simulation time with video_frame_schedule and video_frame_count, or incrementally with LiveVideoSampler. export_animation uses the same rule for stored and live frames. The separately installed Studio subpackage opens a browser workspace with studio(recorder). With a Makie backend loaded, export_figure and export_animation produce static output; fieldaxis, amrfield, amrfield!, and diagnosticsgrid! compose custom layouts. rasterize, locate, locate_face, and ViewCamera provide graphics-independent field sampling and view geometry.

TwoPhaseAMR.BlockTreeMesh — Method
BlockTreeMesh(; base_mesh=block_size, block_size=(16, 16), halo=1,
                origin=(0.0, 0.0),
                extent=(1.0, 1.0), periodic=(true, true), max_level=0,
                refine=(key, origin, extent) -> false,
                adaptation=MeshAdaptationOptions())

Build a serial 2-D forest of fixed-size Cartesian quadtree leaf blocks. base_mesh is the global level-zero cell count and must be an integer multiple of block_size in each direction. The resulting permanent base roots may be refined but never coarsened away. refine is called for every candidate block up to max_level. The forest is automatically refined until it is fully 2:1 balanced (including corners). Neighbours and halo donors are determined from integer block-key lattices, including periodic seams, independently of floating-point domain coordinates. Execution and halo schedules are then materialized, so numerical kernels never traverse the trees. max_level remains the refinement ceiling for subsequent dynamic adaptation; its frequency, base-level, and coarsening-hysteresis controls are stored in adaptation.

TwoPhaseAMR.CMDGFMProjectionStats — Type

Diagnostics for one conservative multidimensional ghost-fluid projection.

The mixture and normal-velocity defects are dimensionless and report the actual projected state: dt * max(abs(div(u_mix))) and the maximum of dt * abs(jump_row) / h_face, respectively. Here h_face is the smallest cell edge among the two adjacent cells, so a coarse–fine face uses the fine-cell minimum edge. The algebraic convergence check also bounds dt^2 * max(abs(r_pressure) / cell_volume), including the pressure rows omitted to fix the gauge, and dt^2 * max(abs(r_jump) / h_face). For a shortened step retaining an inherited mixture-flux defect, convergence measures the mixture deviation from that target but still requires the actual normal defect to be within tolerance.

TwoPhaseAMR.CurvatureRefinementIndicator — Type
CurvatureRefinementIndicator(interface; cells_per_radius=8,
                              coarsen_ratio=1/3, minimum_level=0,
                              maximum_level=interface.mesh.max_level,
                              t_init=-Inf, t_end=Inf,
                              xmin=-Inf, xmax=Inf, ymin=-Inf, ymax=Inf)

Request refinement where max(dx,dy)*abs(curvature) > 1/cells_per_radius. Following the thesis, a cell mixed in the open fluid volume also requests refinement when no valid LHF exists or when its height columns reveal a thin filament. A block that holds a mixed cell in its own cells or in its one-cell halo borders the interface, and every wall-cut cell of that block which is completely liquid in its open volume then counts as an interface cell: the liquid–gas interface meets the solid there, so its undefined curvature is the unresolved contact line (#148). The test is per block because the refinement decision is: a cell-level test would read a finer neighbour's restriction average at a level step, which is mixed even where the fine interface is resolved, so the coarse block would refine and its own children would coarsen again. Liquid-filled cut cells in blocks without a mixed cell lie away from the interface and stay excluded (#118). Use hysteresis for coarsening; combine with InterfaceRefinementIndicator for a protected band. The criterion is active for t_init <= time <= t_end and enforces its level bounds independently of the curvature estimate. Only blocks intersecting the closed spatial region are eligible; outside it the indicator requests :coarsen without enforcing its minimum level.

TwoPhaseAMR.EllipticOperator — Type
EllipticOperator(mesh; reaction=0, diffusion=1, face_coefficient=1,
                 velocity_boundary=nothing, boundary_face_coefficient=nothing,
                 assemble_matrix=true)

Construct the positive cell-centred operator

L(u) = reaction*u - diffusion*div(face_coefficient*grad(u)).

The matrix is stored in integrated finite-volume form, reaction*M + diffusion*S, where M is the diagonal cell-volume matrix and S is symmetric positive semidefinite. Keeping the reaction and diffusion parts separate makes the same object usable for periodic pressure Poisson problems (reaction=0) and later implicit diffusion solves (reaction>0).

At a mixed-level interface the inverse face metric is non-diagonal. Variable coefficients therefore enter through the symmetric product sqrt(kappa)*K*sqrt(kappa); this preserves gradient/divergence duality and reduces to ordinary face multiplication wherever K is diagonal.

velocity_boundary selects homogeneous Dirichlet data on Outflow() and ZeroGradientVelocity() sides; all other physical sides are homogeneous Neumann. A boundary coefficient may be supplied per physical face with boundary_face_coefficient; otherwise scalars and functions are evaluated at the boundary, and interior coefficient vectors are area-weighted from the opposite normal faces. Supply boundary_face_coefficient if an open face has no opposite interior face. The boundary distance is half the local normal cell spacing. Open boundary conductances participate in the same matrix, factorized action, and weighted gradient.

A zero-reaction operator is singular if at least one active connected component has neither an open Dirichlet conductance nor a nonzero connection to an imposed inactive cell. Gauges are applied only to those components.

Pass assemble_matrix = false for a factorized operator without an assembled matrix; then matrix is nothing. The diagonal slots of an assembled matrix are located once, at construction; a coefficient refresh reuses them so its threaded body cannot throw.

TwoPhaseAMR.FlowSimulation — Type
FlowSimulation(mesh, physics::SinglePhase; options...)
FlowSimulation(mesh, physics::TwoPhase;
               velocity_model=OneVelocityModel(), options...)
FlowSimulation(velocity, pressure, system; workspace=nothing, options...)

High-level owner for an incompressible-flow calculation. It keeps the evolving velocity and pressure together with their Navier–Stokes equation system at flow.system, reusable workspace, current time, cumulative step/mesh-update counters, optional default time step, and diagnostic histories.

Physics, velocity formulation, numerical methods, and adaptivity are explicit:

physics = SinglePhase(density=1.0, dynamic_viscosity=1e-3)
flow = FlowSimulation(
    mesh, physics; dt=1e-3,
    velocity=(x, y, time, axis) -> axis == 1 ? sinpi(2y) : 0.0,
    diagnostics=(KineticEnergy(),))
result = simulate!(flow, 1.0)

For two-phase physics, velocity_model=OneVelocityModel() selects one shared velocity and TwoVelocityModel(...) selects separate liquid/gas velocities. The formulation is never inferred from the shape of an initializer. A shared initializer is accepted in either mode; two-velocity mode also accepts a liquid/gas pair.

dt becomes the default for simulate! and lets the initial workspace build the final shifted diffusion hierarchy once. force, when supplied, is the default body force for step! and simulate!. Velocity may be zero, a constant two-component tuple, a callable f(x,y,time,axis), or compatible existing field data. Pressure may be zero/a number, a callable p(x,y), or a CellField. The fully assembled constructor wraps existing fields, system, and optional workspace without copying.

flow.interface and flow.diffusion_operator expose the active phase interface and viscous operator; the latter is nothing for inviscid two-phase flow.

TwoPhaseAMR.GeometricViscosityAveraging — Type
GeometricViscosityAveraging()

Average phase viscosities by their phase-fraction-weighted geometric mean, mu_liquid^c mu_gas^(1-c) in a cell of conditional liquid fraction c and prod(mu_cell^w) at a shear-stress vertex. TwoPhaseAMR.GradientOperator — Type
GradientOperator(mesh, [T=eltype(mesh.origin)])
GradientOperator(pressure::CellField)

Precompute the geometric Riesz map used by the pressure gradient. The primary divergence remains the oriented sum of fluxes through owned leaf-face segments. The gradient is its negative adjoint in the face inner product induced by the inverse Riesz map.

On a conforming Cartesian mesh the map is diagonal and recovers the ordinary MAC difference. At a coarse–fine interface it is a sparse, symmetric positive definite vertex-patch operator. Its non-diagonal entries provide the wider stencil needed to reproduce affine pressure gradients without modifying the cellwise Gauss divergence.

At a physical boundary the normal pressure correction is homogeneous Neumann: the boundary face gradient is exactly zero. Vertex patches cut by a wall use the diagonal half-face metric, while complete interior patches retain the AMR Riesz map. Thus the cell divergence remains the primal operator and the pressure operator is still symmetric positive semidefinite.

Face displacements are evaluated on the integer lattice of the block keys, not as a difference of absolute cell centres: the normal component is the mean of the two cells' widths and the tangential component is the lattice centre offset scaled by the finest spacing. Both are exact, so the operator of a translated mesh is bitwise the operator of the same mesh at the origin.

A periodic direction is resolved through the covering space: the normal component of the displacement is signed by the face orientation (the plus cell always lies on the +axis side of the face) and only the tangential component takes its sign from the shortest periodic image. A periodic direction resolved by only two cells is therefore supported: the half-period tie of the centre offset cannot flip the seam displacement, and the resulting metric is the ordinary diagonal MAC metric of that direction.

An operator owns one scratch vector and must not be shared by concurrent kernels.

TwoPhaseAMR.HarmonicViscosityAveraging — Type
HarmonicViscosityAveraging()

Average phase viscosities by their series (harmonic) conductance.

In a cell of conditional liquid fraction c the viscosity is 1 / (c / mu_liquid + (1 - c) / mu_gas), and at a shear-stress vertex that spans several cell quarters with weights w, summing to one, it is 1 / sum(w / mu_cell). This is the coefficient that keeps the tangential traction continuous across an interface aligned with the shear, where the centred difference puts the two phases in series; the geometric mean overestimates that flux by a factor 2 sqrt(mu1 mu2) / (mu1 + mu2) (6.07 % for mu = (2, 1)).   1. a conservative staggered convection update (Lax–Wendroff by default and optionally using a three-point limited AMR-interface flux), applied as sequential coordinate sweeps whose order alternates between time steps,

TwoPhaseAMR.StaggeredDiffusionOperator — Method
StaggeredDiffusionOperator(geometry; viscosity=1, boundary=NoSlip())

The conservative cut-cell stiffness is symmetric positive semidefinite. Embedded walls include surfaces aligned with cell faces as well as PLIC cuts. For Cartesian wall segments the tangential closure uses the wall-normal distance and the portion of the segment owned by the dual face. A wall-aligned normal velocity is prescribed zero and removed from the diffusion unknowns. A cut-cell PLIC segment, Cartesian or tilted, is split among the dual faces by their tangential strips and by the mid-plane of the component direction; the conductance of a piece is its length divided by the perpendicular distance from the node to the reconstructed plane, which reproduces the wall flux of a linear velocity exactly. A node whose centre lies inside the solid keeps its piece, so every positive-aperture face stays a projection degree of freedom. Normal contacts take the open area of the cell mid-plane, so a closed flanking primal face cannot halve them. Transverse contact measures use overlaps of the bisected open traces, including across AMR interfaces, and a clipped open trace is bisected at the cell centre. Centred contacts share a linear-exact gradient; an orphaned contact takes the prescribed wall-normal velocity of a no-slip, free-slip or inflow wall as a Dirichlet partner (exact for wall data constant along the wall, first order for wall data that varies along it) and otherwise differences a level-matched pair of unknowns, which is exact for affine velocities; where no level-matched face is available it keeps the linear-exact minimum-norm derivative of the unembedded transition. Domain-wall measures belong only to the dual strips that touch the wall. Advection flux-star redistribution between sibling faces is not a diffusive interface.

TwoPhaseAMR.TreeGeometricMultigridPreconditioner — Type
TreeGeometricMultigridPreconditioner(operator; kwargs...)

Rediscretized geometric multigrid on successively capped block trees and coarser base meshes.

By default, each coarse mesh simultaneously replaces every complete terminal sibling family by its parent; pruning=:deepest instead caps only the current deepest generation. The tree constructor restores 2:1 grading. Below the root level, 2×2 root-block agglomeration continues while both root counts are even and each periodic axis retains at least four cells, subject to coarse_size and max_levels. When further coarsening is unavailable, the last level is factorized directly, even if it exceeds coarse_size. The same compatible elliptic discretization is constructed on every mesh, without a Galerkin P' * A * P product. A coefficient-dependent smoothed cell transfer preserves the active-domain pressure null vector, and its adjoint restricts integrated residuals. Each level projects and gauges only its unanchored connected components, with one coarse constraint per unanchored coarse component; coarsening can change that set. Set multigrid=MultigridOptions(...) to configure the hierarchy and smoothing; individual keywords override its corresponding fields.

TwoPhaseAMR.TreeStaggeredGeometricMultigridPreconditioner — Type
TreeStaggeredGeometricMultigridPreconditioner(operator; kwargs...)

Build the two independent single-phase viscous V-cycles by successively pruning the block tree, then agglomerating 2×2 root blocks where possible, and rediscretizing the staggered Laplacian on every resulting mesh. For a volume-symmetric fine operator, coarse levels use the symmetric conservative stiffness, so equal-sweep V-cycles remain symmetric. No P' * A * P coarse matrix is formed. Bottom component systems with at most 256 unknowns use retained dense LU; larger systems use sparse LU. Configure the hierarchy with multigrid=MultigridOptions(...) or individual keywords.

TwoPhaseAMR.VariableStaggeredDiffusionOperator — Type

Coupled staggered div(2μD(u)) with cell-centred normal stresses and vertex shear stresses. The integrated stiffness is E'WE, so viscosity dissipates kinetic energy for positive μ. Density enters the time-step mass matrix.

dirichlet_faces contains prescribed zero global face indices. Their original physical strain columns are stored in wall_reaction_strain, with the same stress rows as strain and columns ordered like dirichlet_faces; its algebraic constraint rows are zero. For retained velocities u, the integrated force on those faces is -wall_reaction_strain' * (stress_weights .* (strain * u)), using the current stress weights.

TwoPhaseAMR.VorticityRefinementIndicator — Type
VorticityRefinementIndicator(velocity; refine_tolerance,
    coarsen_tolerance=refine_tolerance/3, minimum_level=0,
    maximum_level=velocity.mesh.max_level, t_init=-Inf, t_end=Inf,
    interface=nothing, phase=:liquid,
    xmin=-Inf, xmax=Inf, ymin=-Inf, ymax=Inf)

Block AMR criterion from the thesis. Refine if any cell in a block has max(dx,dy)*abs(vorticity) > refine_tolerance; coarsen when every cell lies below coarsen_tolerance. The strict hysteresis condition 2coarsen_tolerance < refine_tolerance prevents immediate re-refinement after coarsening. The criterion is active for t_init <= time <= t_end and enforces its level bounds independently of the vorticity estimate. Only blocks intersecting the closed spatial region are eligible; outside it the indicator requests :coarsen without enforcing its minimum level.

For an intrinsic phase velocity, supply its interface and phase, or register the velocity tuple and interface together in AMRWorkspace. Absent-phase cells do not constrain coarsening. The phase curl extends only valid values into its temporary interface stencil; owned absent velocities remain NaN.

TwoPhaseAMR.WYAdvectionWorkspace — Type
WYAdvectionWorkspace(interface; ctu_threshold=0.5)

Reusable WY sweep arrays; reconstruct after regridding by creating a new workspace. liquid_flux and gas_flux contain signed, time-integrated volumes on owned faces from the most recent complete step, in the same order as mesh.faces. Intrinsic phase values are recovered with the interface's fraction_floor; the same threshold removes small VOF fragments. The modified staggered flux interpolant switches to CTU when either adjacent predicted phase fraction is below ctu_threshold. The workspace uses its interface's fixed geometry and, for a geometry field, freezes the liquid/gas subface ordering there. Cell-scalar source and increment buffers grow on demand and are reused across steps and resized when the workspace is retargeted after mesh adaptation.
