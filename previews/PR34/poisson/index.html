Geometric multigrid and pressure projection

Operator contract

The cellwise Gauss divergence remains the primal operator. Let C be the oriented cell-to-face incidence matrix, A the diagonal matrix of face-segment areas, V the diagonal cell-volume matrix, and K the inverse face Riesz map constructed by GradientOperator. The existing operators are

\[D = -V^{-1} C^T A, \qquad G = K A C.\]

The positive integrated Poisson stiffness is therefore

\[S = -V D G = C^T A K A C.\]

EllipticOperator stores the canonical shifted form

\[\mathcal L u = a u - b\,\nabla\cdot(\kappa\nabla u), \qquad A_h = aV + bS_\kappa.\]

PoissonOperator(mesh) selects a=0, b=1. For implicit midpoint viscosity, the StaggeredEllipticOperator uses the shifted coefficient b=dt*nu/2.

For a diagonal Cartesian face metric, a face coefficient simply multiplies the ordinary normal gradient. At a refinement interface K is non-diagonal, so left multiplication by a diagonal coefficient would generally destroy symmetry. The implemented extension is

\[S_\kappa = C^T A \sqrt{\kappa}\,K\sqrt{\kappa}\,A C.\]

It is symmetric positive semidefinite, preserves constants, and reduces to the ordinary coefficient-weighted stencil in every conforming region. The public harmonic_face_coefficients helper forms distance-weighted harmonic means from positive cell values, including unequal half-cell distances at a coarse–fine face. weighted_gradient! applies precisely the flux gradient used in S_κ; the projection never reconstructs a second, inconsistent coefficient-weighted gradient.

Tree-geometric hierarchy

The hierarchy follows the block tree itself. Each coarse mesh replaces terminal sibling blocks with their parent while restoring 2:1 grading. With pruning=:all, every available terminal family is removed in a pass; pruning=:deepest removes only the deepest generation. Cells inside a block retain the configured block size, so an 8×8 block gives at most 64 cell-centred unknowns on the root grid.

Every level rebuilds the compatible pressure operator on its own composite mesh. Face coefficients are restricted by geometric overlap, then the coarse stiffness and metric are assembled directly. The implementation never forms Pᵀ A P. A coefficient-dependent smoothed cell interpolation preserves constants, and its adjoint restricts integrated residuals.

V-cycles use pre- and post-damped-Jacobi relaxation. The root-grid sparse matrix is factorized once as the bottom solver; periodic and all-Neumann pressure use the volume-weighted nullspace augmentation. V-cycle work vectors are cached. Across AMR updates, matching coarse tree levels, transfers, operators, and work storage are retained and refreshed in place.

TreeGeometricMultigridPreconditioner implements three-argument ldiv! and contains no Krylov policy. EllipticSolver composes it with a Krylov.jl workspace. The :geometric selector also selects this tree implementation.

Staggered shifted hierarchy

The viscous problem has two separate sets of unknowns: face-normal velocities on the x- and y-dual grids. Their integrated midpoint matrices are

\[A_a = M_a\left(I-\frac{\Delta t\nu}{2}L_a\right), \qquad a\in\{x,y\}.\]

TreeStaggeredGeometricMultigridPreconditioner prunes the same block tree and reconstructs StaggeredDiffusionOperator on every coarse composite mesh. Face interpolation is geometric: coincident faces use tangential overlap, and newly exposed faces interpolate between adjacent coarse face planes. Both searches use sorted lattice-line indexes: binary interval lookup visits only overlapping segments, and an outward walk finds the nearest bracketing normal lines without rescanning every coarse face. Restriction is its adjoint. Each coarse matrix contains the single-phase Laplacian and the same wall and AMR consistency closures as that mesh's fine operator; no Galerkin product is used.

The corrected AMR Laplacian is mildly nonsymmetric, so StaggeredEllipticSolver uses right-preconditioned BiCGSTAB by default. Each component has its own V-cycle and sparse root factorization. A fixed time step retains the hierarchy, while a coefficient change refreshes the shifted matrices. Matching levels are reused after an AMR topology change. The :geometric selector also selects this tree implementation.

Preconditioner choices

The built-in and optional choices use one constructor interface:

nothingnoneyesyes

The optional packages are weak dependencies. Import the selected package before constructing the solver, for example import AlgebraicMultigrid. For staggered diffusion, the named :amg, :ilu, and :ichol choices are built from the symmetric stable-core matrix but precondition a Krylov solve using the exact corrected matrix. A custom factory or pre-built (x=..., y=...) preconditioner remains available when direct access to the corrected matrices is desired. AMG supports smoothed aggregation and Ruge–Stuben setup; incomplete LU exposes its drop tolerance; and incomplete Cholesky exposes limited fill, dropping, and a diagonal shift. Options are passed through preconditioner_options.

ILU is intentionally not presented as a CG preconditioner because a generic ILU factorization need not be symmetric positive definite. It can still be used for pressure by explicitly selecting Krylov.BicgstabWorkspace.

This follows the established adaptive multigrid pattern. FAC introduced coarse-grid correction on composite adaptive grids. Afivo demonstrates geometric multigrid on fixed, even-sized quadtree/octree blocks, including coarsening below the AMR level. AMReX likewise separates a multilevel solver from canonical constant- and variable-coefficient elliptic operators and uses agglomeration to continue geometric coarsening.

Nullspace and convergence

For periodic or impermeable-wall domains, constants are the only pressure null mode. A non-periodic velocity boundary is set automatically to u dot n = 0, and the normal pressure correction is homogeneous Neumann. solve! fixes the solution by enforcing a volume-weighted zero mean. Its default compatibility=:project removes the volume mean of the strong right-hand side and records it in LinearSolverStats.removed_rhs_mean; compatibility=:error instead rejects incompatible data. The bottom solve uses the augmented system

\[\begin{bmatrix} A & v \\ v^T & 0 \end{bmatrix} \begin{bmatrix} p \\ \lambda \end{bmatrix} = \begin{bmatrix} b \\ 0 \end{bmatrix},\]

where v is the coarse representation of cell volume. Shifted diffusion operators have no nullspace and use an ordinary bottom-grid factorization.

For the manufactured periodic problem

\[-\Delta p = 8\pi^2\sin(2\pi x)\cos(2\pi y),\]

on the standard two-level mesh, the tests give:

API

mesh = BlockTreeMesh(
    block_size=(8, 8), max_level=2,
    refine=(key, origin, extent) ->
        key.level == 0 || (key.level == 1 && key.i == 0 && key.j == 0),
)

operator = PoissonOperator(mesh)
solver = EllipticSolver(operator) # Krylov.jl CG + geometric MG
pressure = CellField(mesh)
rhs = CellField(mesh)
initialize!(rhs, (x, y) -> 8pi^2 * sinpi(2x) * cospi(2y))
stats = solve!(pressure, solver, rhs; rtol=1e-10)

# The layers can also be assembled explicitly.
using Krylov
multigrid = TreeGeometricMultigridPreconditioner(operator)
krylov = Krylov.CgWorkspace(operator.matrix, zeros(ncells(mesh)))
explicit_solver = EllipticSolver(operator, krylov, multigrid)

# Optional AMG integration.
import AlgebraicMultigrid
amg_solver = EllipticSolver(operator; preconditioner=:amg)

velocity = FaceVelocity(mesh, velocity_function)
projection = ProjectionWorkspace(solver)
project!(velocity, pressure, solver, dt, projection; tolerance=1e-8)

The standalone algebraic solve! retains rtol and atol for expert use. The physical project! API instead accepts one dimensionless tolerance and solves with the absolute strong-residual target tolerance/dt^2. Consequently stats.final_linf/stats.residual_scale equals dt^2*stats.final_linf, because stats.residual_scale = 1/dt^2. This is the maximum fractional volume defect left by the projection, up to the reported roundoff-limited target.

preconditioner may also be a factory accepting the sparse matrix or a pre-built object implementing ldiv!(destination, preconditioner, source). krylov may be a supported Krylov.jl workspace factory or, for a cell elliptic solve, a pre-built compatible workspace. CG, BiCGSTAB, GMRES, and FGMRES workspaces are supported. Method-specific settings such as restart=true and reorthogonalization=true are supplied through krylov_options; the package retains control of residual tolerances, iteration limits, and preconditioner placement. The default pressure method is CG. Staggered diffusion selects CG for a symmetric operator and BiCGSTAB otherwise.

The operator and solver setup may allocate; apply!, a warmed solve!, and the projection kernels reuse their workspaces. The implementation is 2-D, uses shared-memory threading, and requires isotropic mixed-level cells through the underlying GradientOperator. Periodic and homogeneous-Neumann pressure-correction boundaries are supported. General pressure Dirichlet/inhomogeneous Neumann data and a structured single-block FFT option remain future extensions.
