Example catalogue

The files under examples/ are complete, standalone applications rather than hidden test helpers. Each exposes run_example, runs headlessly by default when included, enables visualization when executed from a terminal, and lets simulate! choose a stable timestep.

For a quick first run, set max_level=0 and a short final_time. For example:

include("examples/interfacial_instability.jl")
run = run_example(
    max_level=0,
    final_time=0.02,
    velocity_model=OneVelocityModel(),
)

The returned value contains the flow and simulation result, so diagnostics can be inspected without visualization. Direct execution prints print_simulation_summary. Full convergence studies and literature comparisons live under test/integration/; the examples are intentionally focused on one inviting physical setup.
