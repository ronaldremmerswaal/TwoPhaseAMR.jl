TwoPhaseAMR.advect! — Method
advect!(field, advecting, dt, workspace;
        scheme=LW(),
        amr_interface_scheme=default_amr_interface_scheme(scheme))
advect!(velocity, dt, workspace;
        scheme=LW(),
        amr_interface_scheme=default_amr_interface_scheme(scheme))

Advance both components of a staggered vector field. Within one coordinate sweep, both component tendencies are evaluated from the same input and then both components are published. The next coordinate sweep therefore consumes one consistent intermediate vector rather than updating x and y velocity components separately. The one-velocity shorthand also uses each published intermediate as its advecting field. By default LW and centred transport use MC on non-regular AMR connections, upwind remains globally upwind, and a selected three-point scheme is retained.

TwoPhaseAMR.advect! — Method
advect!(field, velocity, dt, workspace;
        scheme=LW(),
        amr_interface_scheme=default_amr_interface_scheme(scheme))

Advance a directional face field using conservative fluxes through its staggered control volumes. Lax–Wendroff uses two full directional sweeps, publishing the first intermediate before evaluating the second and alternating x/y with y/x order on successive calls. The variable-coefficient LW predictor includes the directional dual divergence of the transporting velocity; the two directional divergence terms cancel for a divergence-free velocity only after both sweeps. On a uniform constant-velocity line it reduces to classical one-dimensional LW. By default LW and centred transport use MC on non-regular AMR connections, upwind remains globally upwind, and a selected three-point scheme is used at the interface as well.

TwoPhaseAMR.convection! — Method
convection!(destination, advected, velocity, dt, workspace;
            scheme=LW(),
            amr_interface_scheme=default_amr_interface_scheme(scheme))

Evaluate the conservative staggered convection operator div(I(velocity) q) on owned dual control volumes. scheme may be Upwind(), Centred(), LaxWendroff(), Fromm(), Minmod(), MC(), VanLeer(), or Superbee() (the corresponding symbols are also accepted) and defaults to LW().

For LW and positive dt, the returned rate is the effective rate of the next directionally split step. Each step has two full sweeps; their order alternates between x/y and y/x on successive advect! calls. Every sweep consumes the preceding intermediate field. Thus destination == (advected - advect(advected, dt)) / dt without advancing the workspace's order flag; x and y fluxes are not accumulated from one old state. At dt == 0, the limiting spatial operator is evaluated directly.

For an all-centred operator (scheme=Centred() and amr_interface_scheme=Centred()), the face value is the equal-weight average. On every supported periodic mesh this makes twice the convection-matrix diagonal equal the volume-weighted interpolation of the primary cell divergence. The operator is therefore volume-weighted skew-symmetric for a discretely divergence-free velocity, including across refinement interfaces.

On a mixed-level mesh, amr_interface_scheme selects the state used only on non-regular factored connections. Its default is selected from scheme: upwind remains upwind, centred and LW use MC, and a three-point scheme uses itself. Upwind at an AMR interface is rejected unless the bulk scheme is also upwind; an interface-only first-order closure has poor accuracy. The four limited variants revert to upwind at a local extremum. A hanging connection without an unambiguous upstream direction also falls back to upwind. Explicit Centred() retains the diagonal and skew identities throughout the mesh. The keyword is accepted but has no effect on a uniform mesh.

TwoPhaseAMR.dynamic_viscosity — Method
dynamic_viscosity(interface; viscosity)

Return the cell-centred dynamic viscosity used by the one-velocity diffusion operator. Following the thesis, the coefficient is the phase-fraction- weighted geometric mean

mu = mu_liquid^c * mu_gas^(1-c), where c is the liquid fraction within the open fluid part of a cut cell.

At shear-stress vertices the operator volume-interpolates c before applying the same formula. Equivalently, it geometrically averages this returned field, because log(mu) is affine in c.

TwoPhaseAMR.project! — Method
project!(velocity, pressure, solver, dt, workspace;
         tolerance=sqrt(eps(T)), max_cycles=100)

Apply the pressure projection using exactly the weighted gradient in the solver's Poisson operator. Physical face velocities are first set to zero; the corresponding pressure correction has homogeneous Neumann data. The pressure is overwritten by the mean-zero solution of -diffusion*D*G_kappa*p = -D*u/dt, then u <- u - dt*diffusion*G_kappa*p. Following Basilisk, tolerance bounds the maximum fractional cell-volume defect left by the projection: dt^2 * norm(residual, Inf) <= tolerance (up to the roundoff floor).

source
TwoPhaseAMR.simulate! — Method
simulate!(velocity, pressure, solver, final_time, workspace;
          time=0, dt=nothing, cfl=0.45,
          diagnostics=NoDiagnostics(), step_offset=0,
          visualization=NoVisualization(),
          tolerance=sqrt(eps(T)), max_cycles=nothing)

Advance to final_time. If dt is omitted, a stable step is chosen initially and retained while it remains below the current bound, which also reuses the shifted viscous hierarchy and bottom factorization. Returns the final time, number of steps, latest projection statistics, and the number of topology changes. When the solver has refinement indicators, they are evaluated after a successful physical step; field transfer does not add a time-integration or pressure-correction step. A supplied visualization receives the initial state, every completed step, and the final state. During initialization it is also given a lazy independent-step procedure. A visualization may use that procedure to advance copied state without replacing or subdividing a step on the actual simulation path.

solve!(solution, solver, rhs; rtol=1e-10, atol=0,

TwoPhaseAMR.step! — Method
step!(velocity, pressure, solver, dt, workspace;
      time=0, force=nothing, tolerance=sqrt(eps(T)),
      max_cycles=nothing)

Advance one split momentum step followed by exactly one pressure projection. Both single- and two-phase configurations execute the same staged procedure. force, when present, is sampled as force(x, y, time, axis) at the time midpoint and added to the transported state before diffusion, preserving the single-phase solver's established splitting. Thesis phase forces are added after diffusion so hydrostatic equilibria are unchanged by the viscous solve. The transporting flux is frozen at the old-time velocity while each coordinate sweep updates both transported velocity components. No-permeation is automatic in non-periodic directions.

TwoPhaseAMR.step! — Method

Advance one two-velocity Navier–Stokes step.

The geometric interface and both intrinsic phase velocities use the same transport stage as the passive two-velocity API. Body force, surface tension, and gravity modify the predictor, so their contribution is present in the two right-hand sides of the subsequent three-block mimetic projection. Viscosity acts implicitly on the phase-mass weighted one-velocity state; its common increment is then applied to both phases, conserving combined momentum and preserving the intrinsic velocity jump.

TwoPhaseAMR.surface_tension! — Method
surface_tension!(acceleration, interface, pressure_operator, workspace;
                 sigma, formulation=CGFM(), curvature=nothing)

Overwrite acceleration with CSF or conservative GFM surface tension. The optional constant curvature is for isolating the balanced-force identity in tests. Otherwise use fraction-weighted LHF/GHF curvature. Missing curvature on an active interface face raises an error. The same weighted inverse metric as pressure is applied to the curvature-weighted phase jump, including on AMR.
