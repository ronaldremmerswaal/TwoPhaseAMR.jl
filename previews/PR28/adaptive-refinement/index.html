Dynamic adaptive refinement

BlockTreeMesh remains the package's only mesh type. Its global base_mesh is partitioned into permanent roots according to block_size, with one RegionTrees quadtree per root. These trees can be refined and coarsened in place, but their level-zero roots cannot be removed. The leaf, face, and halo schedules are rebuilt only after the active leaf set changes. Numerical operators still traverse flat schedules rather than the trees.

Refinement criteria and arbitration

The first criterion is a centred interpolation-defect estimate for a cell-average field. For every owned cell it compares the stored value with the average of its four axial neighbours and normalizes the defect by the largest local magnitude (and a small positive floor). The largest cell defect in a block determines its request:

  • error greater than E_refine: :refine;
  • error less than E_coarsen: :coarsen;
  • otherwise: :keep.

Thus E_coarsen < E_refine supplies value hysteresis. When several criteria are present, their requests are combined in the strict order :refine > :keep > :coarsen. A sibling family is coarsened only if all four children request coarsening. Refinement-only closure after arbitration restores the 2:1 condition, including corner neighbours, so grading can override a coarsening request.

Every built-in criterion is active on the inclusive physical-time interval t_init <= time <= t_end; the defaults t_init=-Inf and t_end=Inf keep it active throughout a run. simulate! passes the current physical time to AMR. When calling the lower-level API directly, pass the same time as adapt!(amr, criteria; step, time). An inactive criterion makes no refinement or keep request, so the other active criteria retain control and the mesh may coarsen normally.

Error-based criteria (InterpolationErrorIndicator, CurvatureRefinementIndicator, and VorticityRefinementIndicator) have independent minimum_level and maximum_level bounds. The fixed-band criteria InterfaceRefinementIndicator and GeometryRefinementIndicator instead have one exact target level: blocks near the phase interface or embedded solid boundary move toward that level, while blocks outside the band request coarsening. Both detect boundaries aligned with cell faces through halo jumps.

MeshAdaptationOptions adds temporal hysteresis. update_interval limits adaptation attempts in a solver run, coarsen_delay prevents a newly created child from being coarsened for the given number of completed simulation steps, and minimum_level protects a base level.

mesh = BlockTreeMesh(
    block_size = (16, 16), max_level = 4,
    adaptation = MeshAdaptationOptions(
        update_interval = 5, coarsen_delay = 20, minimum_level = 1
    )
)

marker = CellField(mesh)
temperature = CellField(mesh)
velocity = FaceVelocity(mesh, (x, y, time, axis) -> 0.0)
pressure = CellField(mesh)

criterion = InterpolationErrorIndicator(
    marker; E_refine = 0.08, E_coarsen = 0.025,
    minimum_level = 1, maximum_level = 4,
    t_init = 0.0, t_end = 1.0
)
system = NavierStokesSystem(
    mesh; density = 1.0, dynamic_viscosity = 1.0e-3,
    refinement_indicators = (criterion,),
    adaptive_fields = (temperature,)
)
workspace = NavierStokesWorkspace(system)

simulate!(velocity, pressure, system, 1.0, workspace)

Velocity, pressure, every refinement-criterion field, and every entry in adaptive_fields are transferred. The time integrator takes no extra physical step and performs no extra pressure correction: after transfer it only rebuilds the topology-dependent advection, diffusion, pressure, and Krylov workspace state. simulate! reports the number of actual topology changes as result.mesh_updates.

The lower-level interface accepts either criteria or one explicit label per active block:

amr = AMRWorkspace(mesh, pressure, velocity, temperature)
labels = refinement_labels!(amr, criterion; time = 0.4)
statistics = adapt!(amr, labels; step = 100)

Transfer operators and invariants

Cell data are interpreted as finite-volume averages. Restriction is the volume average of the four fine cells. Prolongation is a conservative piecewise-linear reconstruction: monotonized-central slopes produce the four subcell averages, whose mean is exactly the parent average. It is affine exact and second order in smooth monotone regions, while limiting deliberately reduces it to first order at extrema and non-smooth interfaces.

Generic face fields use area averaging for restriction. Prolongation first reconstructs the tangential variation with the same limited linear slope and then interpolates between old normal face lines. For a FaceVelocity, newly created internal faces receive an additional local incidence correction: each fine cell over an old coarse cell is assigned one quarter of the old integrated divergence. This preserves a discretely divergence-free velocity without a second projection. On periodic component-normal directions, a uniform divergence-free correction also preserves the discrete staggered momentum to roundoff. At physical component-normal boundaries the boundary half-control volumes are not owned momentum unknowns, so no global momentum correction is applied; this retains affine exactness and does not inject boundary-cell divergence.

The implementation reuses the mesh schedule vectors, face-field vectors, label and geometry scratch, and pools discarded cell-block matrices. A repeated refine/coarsen/refine cycle therefore reuses cell payload storage. A real topology change cannot be fully allocation-free: RegionTrees nodes, temporary connectivity dictionaries, face/halo schedule entries, and the new elliptic hierarchies must be constructed. These costs are intentionally measured separately from the allocation-free restrict! and prolong! kernels in the adaptivity group of the current benchmark suite.

Face transfer groups the old face segments by exact normal lattice coordinate. Each line is sorted once. Interval queries use binary lookup followed by a walk over only the overlapping segments; interpolation to a newly exposed face walks outward from the insertion point until it finds the two local bracketing lines. It therefore does not scan all old faces or all normal coordinates for each new face. Cell ownership and halo donors use quadtree leaf descent.

Visualization frames carry an immutable, shared snapshot of their topology, so nearest-solution checkpoints remain displayable after later regrids. Exact off-grid checkpoints are currently rejected with dynamic adaptation because an independent side step would require a historical clone of the tree and all topology-dependent solver state.

Accuracy expectations

Adaptive refinement preserves cell-integrated scalars, phase volume, and the discrete divergence constraint of transferred face velocity. Smooth localized flows retain close to second-order global velocity convergence when the criteria resolve their active region. Compare at least two maximum levels: a criterion that never activates can produce a plausible-looking but under-resolved result.

The block-tree projection setting follows the line of adaptive incompressible flow solvers introduced by Popinet (2003). Phase-interface refinement and conservative free-surface transfer are also described by van der Plas (2017) and Remmerswaal (2023).
