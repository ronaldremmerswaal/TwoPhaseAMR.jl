Method reference

The technical reference PDF is a chapter-by-chapter map of the numerical methods and their differences from the thesis. It is a skeleton: detailed derivations and verification results are not yet supplied. For the background and thesis notation, see Ronald A. Remmerswaal, Numerical Modelling of Variability in Liquid Impacts (2023), doi:10.33612/diss.562133319.

For a local documentation build, first build the PDF in docs/techref/ with latexmk -pdf -interaction=nonstopmode -halt-on-error techref.tex. docs/make.jl copies the resulting PDF into the site when it exists. In CI the PDF is built and downloaded before the site is generated.
