Public API

TwoPhaseAMR — Module

Tree-native block-adaptive finite-volume operators for single-phase and incompressible one- and two-velocity two-phase Navier–Stokes flow.

source

NavierStokesSystem is the preferred name for the configured PDE system. NavierStokesSolver and IncompressibleNavierStokesSolver remain available for compatibility. The solvers/ source area is reserved for linear solvers.

Compact standard API

Most applications need only this surface:

TaskStandard entry points
meshBlockTreeMesh, MeshAdaptationOptions
physicsSinglePhase, TwoPhase, SurfaceTension
velocity modelOneVelocityModel, TwoVelocityModel
numerical policyNavierStokesOptions, LinearSolverOptions, MultigridOptions, Adaptivity
run and inspectFlowSimulation, simulate!, diagnostic_history, print_simulation_summary
optional live viewVisualizationFieldRegistry, VisualizationSession, visualize

The remaining exports are supported advanced building blocks for custom operators, low-level stepping, validation, and visualization backends. Their presence does not imply that an introductory application must assemble those layers manually. Compatibility names such as NavierStokesSolver, NavierStokesSimulation, and the non-tree multigrid names are intentionally outside the standard surface.

Interface transport and two-velocity projection are meaningful only for TwoVelocityModel. Surface-tension force selection applies to either velocity model. A liquid/gas velocity tuple is rejected by OneVelocityModel instead of silently changing the formulation.

A nonnegative number is shorthand for the default conservative ghost-fluid choice: surface_tension=0.05 is equivalent to surface_tension=SurfaceTension(0.05; method=CGFM()).

The compatibility entry points remain supported, but new code should compose the physical model and numerical choices explicitly:

Do not pass both interface_transport and interface_method; construction rejects the ambiguous combination. A tuple of liquid/gas initial velocities does not select a model implicitly: pass velocity_model=TwoVelocityModel(). Invalid surface-force, transport, and projection objects are rejected during configuration rather than during a time step.

Diagnostics

Built-in diagnostics are KineticEnergy, PotentialEnergy, SurfaceEnergy, TotalEnergy, LinearMomentum, PhaseVolume, PhaseMass, InterfaceMeasure, MaximumVelocity, CFLTimeStep, DivergenceNorm, LeafBlockCount, and CellCount. Add custom reductions with Diagnostic or add_diagnostic!. Sampling schedules are EveryStep, EveryNSteps, and EveryTimeInterval. Use print_simulation_summary for an end-of-run model, mesh, solver, AMR, and diagnostics report.

See Diagnostics for definitions and visualization subscription.

Lower-level layers

The high-level API does not introduce duplicate field representations. Advanced users can work directly with:

  • fields, placements, halo exchange, and conservative transfer;
  • mesh-adaptation workspaces and refinement criteria;
  • cell and staggered advection/diffusion operators;
  • interface reconstruction and compatible phase transport;
  • scalar and staggered elliptic operators;
  • Krylov and multigrid workspaces;
  • visualization registries and checkpoint sessions.

TwoPhaseAMR.BlockTreeMesh — Method
BlockTreeMesh(; base_mesh=block_size, block_size=(16, 16), halo=1,
                origin=(0.0, 0.0),
                extent=(1.0, 1.0), periodic=(true, true), max_level=0,
                refine=(key, origin, extent) -> false,
                adaptation=MeshAdaptationOptions())

Build a serial 2-D forest of fixed-size Cartesian quadtree leaf blocks. base_mesh is the global level-zero cell count and must be an integer multiple of block_size in each direction. The resulting permanent base roots may be refined but never coarsened away. refine is called for every candidate block up to max_level. The forest is automatically refined until it is fully 2:1 balanced (including corners). Execution and halo schedules are then materialized, so numerical kernels never traverse the trees. max_level remains the refinement ceiling for subsequent dynamic adaptation; its frequency, base-level, and coarsening-hysteresis controls are stored in adaptation.

TwoPhaseAMR.EllipticOperator — Type
EllipticOperator(mesh; reaction=0, diffusion=1, face_coefficient=1)

Construct the positive cell-centred operator

L(u) = reaction*u - diffusion*div(face_coefficient*grad(u)).

The matrix is stored in integrated finite-volume form, reaction*M + diffusion*S, where M is the diagonal cell-volume matrix and S is symmetric positive semidefinite. Keeping the reaction and diffusion parts separate makes the same object usable for periodic pressure Poisson problems (reaction=0) and later implicit diffusion solves (reaction>0).

At a mixed-level interface the inverse face metric is non-diagonal. Variable coefficients therefore enter through the symmetric product sqrt(kappa)*K*sqrt(kappa); this preserves gradient/divergence duality and reduces to ordinary face multiplication wherever K is diagonal.

TwoPhaseAMR.FlowSimulation — Type
FlowSimulation(mesh, physics::SinglePhase; options...)
FlowSimulation(mesh, physics::TwoPhase;
               velocity_model=OneVelocityModel(), options...)
FlowSimulation(velocity, pressure, system; workspace=nothing, options...)

High-level owner for an incompressible-flow calculation. It keeps the evolving velocity and pressure together with their Navier–Stokes equation system, reusable workspace, current time, cumulative step/mesh-update counters, optional default time step, and simulation-owned diagnostic histories.

Physics, velocity formulation, numerical methods, and adaptivity are explicit:

physics = SinglePhase(density=1.0, dynamic_viscosity=1e-3)
flow = FlowSimulation(
    mesh, physics; dt=1e-3,
    velocity=(x, y, time, axis) -> axis == 1 ? sinpi(2y) : 0.0,
    diagnostics=(KineticEnergy(),))
result = simulate!(flow, 1.0)

For two-phase physics, velocity_model=OneVelocityModel() selects one shared velocity and TwoVelocityModel(...) selects separate liquid/gas velocities. The formulation is never inferred from the shape of an initializer. A shared initializer is accepted in either mode; two-velocity mode also accepts a liquid/gas pair.

dt becomes the default for simulate! and lets the initial workspace build the final shifted diffusion hierarchy once. Velocity may be zero, a constant two-component tuple, a callable f(x,y,time,axis), or compatible existing field data. Pressure may be zero/a number, a callable p(x,y), or a CellField. The fully assembled constructor wraps existing fields, system, and optional workspace without copying.

The keyword-only FlowSimulation(mesh; density, dynamic_viscosity, ...) constructor remains available as a compatibility path. Prefer typed physics and NavierStokesOptions in new code. flow.interface and flow.diffusion_operator expose the active phase interface and viscous operator; the latter is nothing for inviscid two-phase flow.

TwoPhaseAMR.GradientOperator — Type
GradientOperator(mesh, [T=eltype(mesh.origin)])
GradientOperator(pressure::CellField)

Precompute the geometric Riesz map used by the pressure gradient. The primary divergence remains the oriented sum of fluxes through owned leaf-face segments. The gradient is its negative adjoint in the face inner product induced by the inverse Riesz map.

On a conforming Cartesian mesh the map is diagonal and recovers the ordinary MAC difference. At a coarse–fine interface it is a sparse, symmetric positive definite vertex-patch operator. Its non-diagonal entries provide the wider stencil needed to reproduce affine pressure gradients without modifying the cellwise Gauss divergence.

At a physical boundary the normal pressure correction is homogeneous Neumann: the boundary face gradient is exactly zero. Vertex patches cut by a wall use the diagonal half-face metric, while complete interior patches retain the AMR Riesz map. Thus the cell divergence remains the primal operator and the pressure operator is still symmetric positive semidefinite. An operator owns one scratch vector and must not be shared by concurrent kernels.

TwoPhaseAMR.IncompressibleNavierStokesSolver — Type
NavierStokesSystem(mesh; density, dynamic_viscosity,
    boundary=NoSlip(), scheme=LW(),
    amr_interface_scheme=default_amr_interface_scheme(scheme),
    pressure_krylov=nothing,
    diffusion_krylov=nothing,
    pressure_krylov_options=(;), diffusion_krylov_options=(;),
    pressure_preconditioner=:auto,
    diffusion_preconditioner=:auto,
    two_velocity_projection=CMDGFMProjection(),
    refinement_indicators=(), adaptive_fields=())

Incompressible Navier–Stokes discretization. Supplying interface selects the one-velocity two-phase coefficients and compatible geometric transport; without it the original single-phase operators are used. Both configurations run the same staged step! procedure. One time step is split into:

  1. a conservative staggered convection update (Lax–Wendroff by default and optionally using a three-point limited AMR-interface flux), applied as sequential coordinate sweeps whose order alternates between time steps,
  2. the optional user body force followed by a Crank–Nicolson/implicit-midpoint staggered viscous solve,
  3. optional phase forces (surface tension and gravity), and
  4. one compatible pressure projection.

density and dynamic_viscosity are material properties in both modes. For single-phase flow they are scalars; the diffusion operator uses the derived kinematic viscosity dynamic_viscosity / density, while the pressure projection uses the inverse density so that the stored pressure has physical units. For two phases they are (liquid, gas) pairs (a scalar dynamic viscosity is also accepted when both phases match). The coupled diffusion operator evaluates the volume-fraction-weighted geometric mean of dynamic viscosity at each normal- and shear-stress location.

The tree may contain static or dynamically adapted local refinement. Optional refinement_indicators are evaluated after completed steps according to the mesh's MeshAdaptationOptions; velocity, pressure, indicator fields, and the additional adaptive_fields are transferred in place before topology-dependent operators are rebuilt. The stored pressure is the latest projection pressure. Automatic Krylov selection uses PCG for symmetric positive (semi-)definite systems and BiCGSTAB otherwise. Thus pressure and coupled two-phase stress diffusion use PCG, while a corrected nonsymmetric single-phase AMR diffusion operator uses BiCGSTAB. Explicit choices take precedence. The two preconditioners are independent. Both configurations use rediscretized tree-geometric hierarchies by default.

For a liquid/gas velocity tuple, two_velocity_projection selects the physical pressure-gradient model. CMDGFMProjection() is the default nonsymmetric conservative multidimensional ghost-fluid system and BiCGSTAB solve. MimeticProjection() selects the symmetric three-block formulation with jointly fitted, smoothed-aperture normal rows. Its only alternate layout is MimeticProjection(variant=:joint_face), which starts from CMDGFM's normal-dominant face selection. Both retain the full jump space and fit local normal/tangential observations before assembling the KKT system.

TwoPhaseAMR.InterfaceField — Type
InterfaceField(mesh; init=0, fraction_floor=sqrt(eps(T)), ...)
InterfaceField(fraction::CellField; fraction_floor=sqrt(eps(T)), ...)

Centred liquid volume fractions and derived, cell-local PLIC planes. The liquid occupies normal_x*ξ + normal_y*η <= intercept, with local coordinates in [-1/2,1/2]^2. reconstruct! refreshes derived data after modifying fractions. The field constructor takes ownership of fraction (it does not copy it).

When an embedded geometry is present, fraction is the liquid volume divided by the complete Cartesian-cell volume. It therefore obeys 0 <= fraction <= geometry.open_fraction. conditional_fraction is the derived liquid fraction within the open part of the cell and is used by PLIC, height functions, and the two-phase constitutive laws.

fraction_floor is the single numerical threshold used by interface cleanup and compatible scalar recovery. Conditional liquid fractions no larger than the floor are set to zero; conditional gas fractions no larger than the floor are removed by setting the liquid fraction to the available open-cell fraction. The default is sqrt(eps(T)).

reconstruction_method=:lhf uses height-function normals with a WY fallback for the PLIC planes. :lhf_ghf retains the original GHF and WY fallbacks. :wy uses WY normals for every mixed-cell PLIC plane. Curvature is still estimated with height functions and GHF fits in all modes, so changing the advection reconstruction does not disable curvature-based refinement or surface tension.

The default static contact angle is π/2 at every non-periodic domain wall and at embedded solid geometry. The angle is used only by the curvature approximation and therefore affects the momentum equation only through the surface-tension force. It never changes the PLIC plane used for advection. Pass contact_angle=nothing to disable the domain-wall curvature condition and embedded_contact_angle=nothing to disable the embedded-wall curvature condition. A four-tuple orders domain angles as (left, right, bottom, top) and may contain nothing entries. For backward compatibility, a scalar contact_angle used together with geometry denotes the embedded contact angle.

TwoPhaseAMR.InterfaceField — Method
InterfaceField(mesh, levelset; atol=1e-10, maxdepth=16,
               min_depth=0, lipschitz=nothing, T=eltype(mesh.origin))
initialize!(interface, levelset; atol=1e-10, maxdepth=16,
            min_depth=0, lipschitz=nothing)

Initialize liquid cell averages from levelset(x,y) <= 0. The function need not be a signed distance. Mixed cells use root-solved height integrals with adaptive Gaussian quadrature, splitting at cell-edge crossings. Geometry that cannot be represented as one height graph is subdivided. atol is the target absolute error in each cell's fraction, not in the domain volume.

An optional global Lipschitz bound (lipschitz=1 for a signed distance) gives a certified pure-cell test and searches same-sign boxes for enclosed components. Without a bound, purity/monotonicity tests are sampled and assume resolved, smooth geometry. Arbitrarily small or oscillatory features cannot be guaranteed from finitely many function samples; min_depth forces a finer initial search. Quadrature error estimates are numerical, not interval-certified error bounds. Failures to resolve geometry or quadrature throw rather than silently accepting an inaccurate fraction. Initialization is transactional: failed quadrature does not modify the existing fraction field. This is an initialization operation; mesh adaptation uses geometric PLIC transfer instead of resampling the level set.

TwoPhaseAMR.InterpolationErrorIndicator — Type
InterpolationErrorIndicator(field; E_refine, E_coarsen,
                            relative_floor=sqrt(eps(T)),
                            boundary=ZeroGradient(), minimum_level=0,
                            maximum_level=field.mesh.max_level,
                            t_init=-Inf, t_end=Inf)

Block indicator for a cell-average field. At every owned cell, compare the stored value with the centred interpolation of its four axial neighbours and normalize by their local magnitude. A block requests :refine when its maximum relative defect exceeds E_refine, :coarsen when it is below E_coarsen, and :keep in between.

The two thresholds provide value hysteresis and must satisfy 0 <= E_coarsen < E_refine. relative_floor prevents a meaningless relative error where the field and all its neighbours vanish. The criterion is active for t_init <= time <= t_end. Its level bounds apply independently of the error thresholds.

TwoPhaseAMR.StaggeredAdvectionWorkspace — Type
StaggeredAdvectionWorkspace(field)

Build the dual-control-volume schedule for a directional FaceField. Fully periodic uniform and 2:1-balanced mixed-level meshes are supported. On AMR, dual fluxes are factored algebraically from the primary face fluxes so that their divergence is exactly the volume-weighted interpolation of the primary cell divergence. Contributions are kept separate by coordinate direction so that an LW sweep never combines x and y fluxes into one update. The schedule also stores the metric-aware upstream predecessor used by three-point fluxes, with an upwind fallback for degenerate hanging connections. It is built once; staggered transport does not traverse the tree.

source
TwoPhaseAMR.StaggeredDiffusionOperator — Type
StaggeredDiffusionOperator(mesh; viscosity=1, boundary=NoSlip())

Construct the componentwise staggered operator viscosity*Δu. In its stable core, fluxes are shared between adjacent dual control volumes, and abrupt AMR stretching is included through the actual face-centre distance. At a split coarse–fine interface the dual-face measure is inherited from the factored primary-flux schedule. A two-ring band uses a linear-exact normal-gradient closure and a wider quadratic Laplacian correction, following the distinction between stretching and splitting made by Van der Plas. The uncorrected integrated stiffness is symmetric positive semidefinite; the corrected AMR operator is generally nonsymmetric but restores consistency and has a left-half-plane spectrum in the tested 2:1 interface configurations.

Physical walls are impermeable. NoSlip() (the default) imposes stationary tangential Dirichlet data; pass NoSlip(f) for a moving wall or FreeSlip() for zero tangential shear. The component matrices and dual volumes are stored explicitly and are reused by the implicit viscous solve.

TwoPhaseAMR.StaggeredEllipticOperator — Type
StaggeredEllipticOperator(diffusion_operator;
                          reaction=1, diffusion=1)

Construct the integrated staggered elliptic problem

reaction*u - diffusion*Δ_h*u.

The same abstract elliptic contract as the cell-centred pressure operator is used, but with dual volumes and one matrix per velocity component. TwoPhaseAMR.TreeGeometricMultigridPreconditioner — Type
TreeGeometricMultigridPreconditioner(operator; kwargs...)

Rediscretized geometric multigrid on successively capped block trees.

By default, each coarse mesh simultaneously replaces every complete terminal sibling family by its parent; pruning=:deepest instead caps only the current deepest generation. The tree constructor restores 2:1 grading. The same compatible elliptic discretization is constructed on every composite mesh, so no Galerkin P' * A * P product is used. A coefficient-dependent smoothed cell transfer preserves the active-domain pressure null vector, and its adjoint restricts integrated residuals. Once the root block is reached, its sparse operator is factorized directly even when it contains more than coarse_size cells.

TwoPhaseAMR.VisualizationSession — Type
VisualizationSession(registry; viewer=NoVisualization(), checkpoints=nothing,
                     checkpoint_dt=nothing, checkpoint_times=nothing,
                     exact_checkpoints=false, live_every=nothing,
                     live_dt=nothing, diagnostic_every=nothing,
                     diagnostic_dt=nothing, asynchronous=false)

Own live copied frames and a fixed checkpoint schedule for one simulation. Specify at most one of:

  • checkpoints=<integer> for that many equispaced checkpoints;
  • checkpoint_dt=<real> for a checkpoint time interval; or
  • checkpoint_times=<vector> for explicit absolute simulation times.

Count and interval schedules include the initial and final times. A count of one retains only the final state. Explicit times are sorted and deduplicated and must fall within the simulated interval.

By default, the completed solution closest to every requested time is retained. With exact_checkpoints=true, the session invokes the independent step procedure supplied when the simulation initializes it. Each off-grid state is advanced from copied solver state and retained without changing the simulation path, whose step sequence and state are unchanged.

Live frames are sampled after every completed step by default. Set live_every=n to sample every n steps or live_dt=interval to sample in simulation time. Initial and final states are always sampled. With asynchronous=true, sampled frames are sent to the viewer through a capacity-one latest-wins mailbox; checkpoints remain lossless. Call request_pause! to request a pause at the next completed-step boundary and resume_simulation! to continue. The Makie viewer exposes the same control. Registered diagnostics are sampled after every step by default. Set diagnostic_every or diagnostic_dt independently of the live-frame policy.
