Literature coverage TODOs

This page tracks implemented numerical ingredients that do not yet have a direct literature reference in the user documentation. It is intentionally a contributor-facing audit: the numerical-method pages contain the references that already support the documented model, while this page identifies the remaining gaps without selecting candidate papers.

A broad background reference near a method does not close an item below. The item is complete only when the exact implemented choice is linked to a primary source, or when the documentation clearly labels it as a package-specific construction and explains its derivation and validation.

Keeping this audit current

When a new numerical option is added, update its method page and bibliography in the same change. If no direct reference is available, add a TODO here and state explicitly whether the implementation is a package-specific extension.
