\chapter{API index}\label{app:api-index}
Public names link to the matching version of the Documenter API. The
implementation boxes at the ends of sections give the relevant names in context;
internal names are given with their source file, linked to the main branch;
\cref{tab:overview:api} lists the public types by the chapter that states them.
An explicit stable anchor for each public function is planned for the API
reference.
