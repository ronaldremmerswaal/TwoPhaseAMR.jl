\chapter*{Reading this reference}
Each chapter states what the code computes: the continuous model, its spatial
(semi-discrete) balance and the fully discrete update, or, for static objects
such as the mesh and its operators, the algebraic map. Derivations and proofs
are not repeated: they are cited, first from the thesis~\cite{remmerswaal2023}
and then from the original literature. The code is normative: where it differs
from the thesis the difference is stated in a box titled \emph{Deviation from
the thesis}; \cref{app:deviations} collects all of them. Each
section ends with an implementation box naming the public API (linked to the
documentation), internal functions (in monospace) and the source lines of the
audited commit. Properties are claimed only when they are proved in a cited
source, follow in one line from the stated definitions, or were checked
numerically; checks give the measured numbers. Every symbol is defined in
\cref{app:notation}. Chapters marked \emph{outline} have not yet been
rewritten in this form.
