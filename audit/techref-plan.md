# TwoPhaseAMR.jl technical equation reference — implementation plan

## Objective, scope and evidence convention

Evolve **the existing `docs/techref/`** into a reader-facing equation reference, not a parallel document and not a proof thesis. Keep the research, bibliography, working LaTeX and publication machinery where correct; replace outline prose with the equations and definitions that let a reader determine exactly what each option computes. Cite Remmerswaal’s [2023 thesis](https://doi.org/10.33612/diss.562133319) first, down to its named section/equation, then the original literature when it adds derivation or context. State the code’s actual variant when it differs; never present thesis formulas as though the implementation used them unchanged.

Every model section must have **continuous model → spatial/semi-discrete balance → fully discrete update**, in conservative form where appropriate, plus definitions of every flux, time level, boundary term, option and default. For inherently static objects (geometry, transfer, diagnostics, or an elliptic linear system), explicitly say “time discretisation: not applicable” and give the algebraic operator or solve, rather than inventing an ODE. For nonlinear split geometric transport, give its face-integral spatial balance and the actual time-integrated donating-region update; do not suggest a unique method-of-lines discretisation exists when it is not implemented. Keep proofs and long derivations in the thesis/papers; short definitions and exact balance identities belong here.

The source locations below are anchors in the **working tree inspected**, not immutable line numbers: projection and Navier–Stokes orchestration are being refactored. `NavierStokesSystem` is already exported and is presently an alias for `IncompressibleNavierStokesSolver` (`src/TwoPhaseAMR.jl:64-66`, `src/navier_stokes/system.jl:57-100`); document the final landed public names, not a speculative rename. Re-resolve symbols and pin the audited commit when the actual reference PRs are prepared. “Check” below means work for those PRs; no Julia, numerical tests or builds were run for this plan.

**Pressure/force detail that must survive the refactor.** With embedded geometry, the common pressure operator for one velocity uses face coefficient $(a_f^o)^2/\bar\rho_f$ (`src/two_phase/forces.jl:125-153`), whereas the two-velocity CMDGFM/mimetic operator intentionally uses $a_f^o/\bar\rho_f$ in the open-dual kinetic norm (`src/two_phase/projection/mimetic_foundation.jl:170-195`). The thesis uses $\zeta$ for a physical pressure **value** jump, e.g. $\zeta=-\sigma\widetilde\kappa$, and $\Xi^\pi$ for the phase coefficient of the pressure-gradient jump (`thesis/st_gfm.tex:32-59,68-75`). Code `data.zeta_liquid=-gas_mass` and `data.zeta_gas=liquid_mass` are the latter $\Xi^\pi$, not the former (`src/two_phase/projection/mimetic_foundation.jl:120-138`, `cmdgfm_projection.jl:1034-1066`). The two-velocity projection gradient recovery contains the common pressure part plus $\Xi^\pi\xi/m_{\rm tot}$; surface tension is instead an explicit predictor force. Document this actual split, and test the conditions under which it is equivalent to a value-jump formulation—do not equate different symbols or presume that the physical surface-tension model is absent. The code’s CSF uses the sharp conditional fraction rather than the thesis’s mollified $\alpha^\epsilon$.

For the mimetic audit, the observed assembled KKT matrix has the structural form $\begin{bmatrix}-S&C&0\\ C^T&D&N^T\\0&N&0\end{bmatrix}$ with RHS `(pressure_rhs, zeros, N*jump_velocity/dt)` (`src/two_phase/projection/mimetic_projection.jl:473-556`). Preserve the actual pressure RHS, inactive-jump and boundary terms when expanding it; this block sketch alone is not a substitute for the complete equation. CMDGFM filters underresolved faces out of the jump unknown set and extends their jump by zero (`cmdgfm_projection.jl:676-705`).

**Further implementation limits.** Single-phase model setup requires strictly positive viscosity (`src/single_phase/physics.jl:11-25`, `src/navier_stokes/system.jl:135-151`); the both-zero viscosity bypass applies to the two-phase path (`src/two_phase/stepping.jl:137-156`). No small-cell merging or flux redistribution was found in the grid survey; open cells remain active however small, so document the explicit CFL rather than claiming such stabilization. The thesis’s edge/curl spaces are useful background, but no public edge field or thesis edge-potential MGO is implemented; the package’s least-squares visualisation curl and local KKT constraints must not be presented as those operators.

## 2. Proposed reader-facing structure and content

Each item migrates material in the existing chapter listed; internal stable IDs below are conceptual section IDs, not promises about final chapter numbering. Each final section ends with an **Implementation** box: relevant public APIs linked, private source functions in monospace, source-file/commit links, defaults/restrictions, and an explicit thesis-deviation box where warranted. Put equations near definitions, not in an API appendix.

1. **Models, scope, and complete step** (`01_overview`, I01–I02). Continuous: single-phase and phasewise conservative mass/momentum, Newtonian stress, $\nabla\!\cdot u^\pi=0$, stress balance, no phase change, interface normal continuity, and one-velocity mixture form; specify which conditions are physical closures rather than separately enforced code. Semi-discrete: discrete mass and momentum as coupled FV balances on I03’s spaces. Fully discrete: stage diagram and exact $n,*,**,***$ ordering including two distinct force placements and boundaries. Cite thesis `basic_navier_stokes.tex:41-48,84-90,128-147,170-191`, `pt2_overview.tex:1`; API `SinglePhase`, `TwoPhase`, `OneVelocityModel`, `TwoVelocityModel`, `NavierStokesSystem`, `FlowSimulation`, `step!`.
2. **Block forest, geometry, spaces and compatible operators** (`02_mesh_amr`, `03_discrete_setting`, parts of `07_cutcells`; I03, I07–I08). Continuous: domain, fixed solid, surface normals and divergence theorem. ## 3. AMR notation extension — concrete proposal

The thesis already defines $\mathcal C$ (cells), $\mathcal F$ (faces), $\omega_f$ (face dual volume), $\mathfrak D$, $\mathfrak S$, $o_{c,f}$ (oriented incidence), $\alpha^\pi$ (volume fraction), $a^\pi$ (aperture), $h_0,h,L$, and the weighted function spaces/integrals; see `nomenclature.tex:3-45,53-81,111-145`, `basic_setting.tex:25-101,193-230`, `basic_amr.tex:1-9`. Reuse these. Add only the following:

- $\mathcal T$ is the **forest** of rooted quadtrees and $\mathcal L(\mathcal T)$ its active leaf blocks. A block $\mathcal B\in\mathcal L$ has level $\ell(\mathcal B)\in\{0,\dots,L\}$ and `BlockKey=(level,i,j)`; four dyadic children exist only for a refined node. $L$ is the configured ceiling; let $L_{\rm act}=\max_{\mathcal B\in\mathcal L}\ell(\mathcal B)$ separately. Let $\mathcal C_\ell$ contain owned cells of leaf blocks at level $\ell$ and $\mathcal C=\dot\bigcup_\ell\mathcal C_\ell$. Each cell is $c=(\mathcal B,i,j)$ with $1\le i\le N_x$, $1\le j\le N_y$; $N_k$ is `block_size[k]`. $h_{0,k}=\operatorname{extent}_k/\operatorname{base\_mesh}_k$ and $h_{\ell,k}=2^{-\ell}h_{0,k}$. In the isotropic special case recover the thesis’s scalar $h_0,h$. Neighbouring leaf blocks, including corners, differ by at most one level (`mesh.jl:924-939`).
- $\mathcal F$ is the set of **owned physical leaf face segments**, including mixed-level segments; use $\mathcal F_\Gamma$ for physical boundary faces and $\mathcal F^{[k]}$ for axis $k$. For a geometric coarse side $\bar f$, define $\mathcal H(\bar f)\subset\mathcal F$ as its fine partition (two segments at a 2:1 transition in 2-D). $\bar f$ is a grouping, not a second stored velocity. On an interior $f$, $c^-(f)$, $c^+(f)$ are `face.minus/plus` and $\boldsymbol n_f=\boldsymbol e_k$; $o_{c,f}=+1$ on $c^-$, $-1$ on $c^+$. On a boundary face use $o_{c,f}=\texttt{face.side}$ and the stored coordinate component. Periodic seams are interior faces. Avoid the skeleton’s $\alpha_{c,f}$ incidence fraction: $\alpha$ already denotes phase volume fraction; use $o_{c,f}$ for signs and $|f|/|\bar f|$ when a geometric fraction is needed.
- $u_f\in\overrightarrow{\mathcal F}$ is a single coordinate-normal **face-segment** velocity; $u_f^l,u_f^g$ are separate intrinsic values for the two-velocity model. $p_c\in\overrightarrow{\mathcal C}$ is cell centred. `FaceVelocity.interior` is in global interior-face order and `FaceField{Axis}` in its axis subsequence, with separate boundary storage (`variables.jl:14-25`). For uncut interiors define the dual volume by the actual metric $|\omega_f|=|f|(h_{\ell(c^-),k}+h_{\ell(c^+),k})/2$ (`mesh.jl:279-292`); this avoids the thesis’s equal-half-cell formula when a coarse side is partitioned. For a solid use $|\omega_f^o|$ from the clipped strips (`embedded/geometry.jl:199-236`), not $a_f^o|\omega_f|$ by assumption. Boundary half-duals need their own definition.
- $c^o=c\setminus c^s$, $\alpha_c^o=|c^o|/|c|$, $\alpha_c^\pi=|c^o\cap\Omega^\pi|/|c|$ and $C_c^\pi=\alpha_c^\pi/\alpha_c^o$ only when $\alpha_c^o>0$. Thus $\alpha^l+\alpha^g=\alpha^o$ and $C^l+C^g=1$ in open cells. Use the code’s shared $a_f^o\in[0,1]$ for an open-face fraction and $a_f^l+a_f^g=a_f^o$ for reconstructed phase apertures. Define covered cells separately, so no division by zero or $0\cdot\mathrm{NaN}$ is hidden.
- For each block use $\mathcal G(\mathcal B)$ for ghost slots, disjoint from $\mathcal C$; $\varphi_g=\sum_{d\in\mathcal D(g)}w_{gd}\varphi_d$ for an internal/periodic halo, with donor/weights defined by the actual four quarter-cell samples (`mesh.jl:881-897`), and state the chosen physical boundary rule separately. A halo is not an extra conserved unknown.
- Write $\mathcal R^{\rm AMR},\mathcal P^{\rm AMR}$ for adaptivity transfers, indexed by field type: cell averaging/MC, geometric PLIC intersection, phase-volume-weighted scalars and face-field interpolation/correction are distinct maps. For a parent cell split into four, $\varphi_c=\frac14\sum_r\varphi_{c_r}$ for full-cell averages; the inverse is the limited-slope formula, not generic injection. For phase fields state their actual weighted amounts, zero-denominator policy and geometric masks (I15).
- Write the integrated signed flux $F_f=|f|a_f^o u_f$ and its timestep-integral $\delta t F_f$ when applicable. The **matching condition** at $\bar f$ is the sum of the two stored fine-segment contributions; each leaf face is computed once and shared by its adjacent cells. The inspected centred scalar/WY composite update is not a level-subcycled algorithm with an additional flux-register reflux step. If the reference mentions refluxing, describe it as the general AMR concept and this code’s shared-face alternative; do not invent an implemented reflux register. Audit other dual transports before extending this statement to them.
- Use a distinct hierarchy counter $j$ and $\mathcal T_j^{\rm MG}$ for successively pruned/agglomerated **solver** meshes; $\mathcal T_0^{\rm MG}$ is the composite physical mesh. $P_j^{\rm MG}$ prolongs a coarse correction; the observed V-cycle uses $(P_j^{\rm MG})^T$ on the integrated residual (`cycles.jl:63-89`), while geometry/material restrictions have their own names. Coarse matrices are rediscretised; do not silently replace them by $P^TAP$. Root agglomeration can continue below physical level zero.
- Use $\boldsymbol\lambda^{\rm KKT}$, explicitly introduced as a multiplier only within the KKT section, to avoid confusing the thesis’s $\lambda$ wavelength. Retain $\delta t$, $\alpha$, $\eta$, $\xi$, $\rho$, $\mu$, $\kappa$, $\sigma$, $\upsilon$, $m$, overbar for the one-fluid equivalent and tilde for staggered quantities. Declare discrete $\chi^l=1_{C^l>1/2}$ (strict tie) where the code uses it.

### Worked sample: composite divergence at a hanging face

This is a specification for the eventual reference, not a claim of a numerical test. Consider an open coarse cell $c$ to the left of two fine neighbours $c_1,c_2$; $f_1,f_2$ are the two *stored* vertical segments, both oriented in $+x$. Other sides and physical boundary contributions are omitted only in the second line. The definition includes embedded geometry and reduces to the uncut operator when $a_f^o=\alpha_c^o=1$:

```latex
\begin{align}
 |c^o|\,(\mathfrak D^o u)_c
   &= \sum_{f\in\mathcal F(c)} o_{c,f}\,|f|\,a_f^o\,u_f,
       \qquad |c^o|>0,\\
 |c^o|\,(\mathfrak D^o u)_c\big|_{\bar f}
   &= |f_1|a_{f_1}^o u_{f_1}+|f_2|a_{f_2}^o u_{f_2},\\
 |c_r^o|\,(\mathfrak D^o u)_{c_r}\big|_{f_r}
   &= -|f_r|a_{f_r}^o u_{f_r}, \quad r=1,2.
\end{align}
```

Thus these three integrated contributions cancel exactly algebraically, subject to floating-point evaluation. In the uncut illustrative case $|c|=4$, $|f_1|=|f_2|=1$, $u_{f_1}=2$, $u_{f_2}=-1$, the coarse contribution is $1/4$ and the two fine *integrated* contributions are $-2$ and $+1$. This directly matches `src/operators/advection/cell_advection.jl:192-205`, `src/embedded/operators.jl:23-56` and the leaf face representation `src/mesh/topology/mesh.jl:32-45`. Covered cells are excluded; nonzero physical-boundary terms use `face.side`. It does **not** assert that the AMR pressure gradient is the naive two-point difference: the actual patch-coupled Riesz map must be inserted before forming the Laplacian (I07).
