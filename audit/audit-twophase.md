# Audit: slice `twophase` (src/indicator/** + src/two_phase/**, 14 230 lines)

Method: static reading and grep across `src/ ext/ test/ examples/ docs/` (name-reference script over all 379 top-level names in the slice, then manual verification), two read-only scouts for the projection and diffusion files (their key claims re-checked by me; items I did **not** re-read are tagged *[scout]*), and one single-threaded Julia session (`-t 1`, BLAS 1 thread, 32×32 block, 52 mixed cells) for the two measurements quoted. Everything not observed is tagged **[INFERENCE]**. No tracked file was modified; scratch is in `/tmp/audit-twophase/`.

## 1. Summary
- The slice is functionally rich but ~5–6 % of it (≈ 700–850 of 14.2 k lines, estimate) is removable duplication, test-only "reference" code, a never-used matrix-free option and compatibility shims. Almost no function is completely dead (only 2 test-only helpers).
- Biggest structural debts: (1) CMDGFM and Mimetic projections duplicate ~170 lines and the Mimetic path rebuilds *all* operators every step; (2) `variable_diffusion_*` re-implements the multigrid-hierarchy builder, the Krylov/residual driver and the coefficient-refresh map of `src/solvers` + `src/operators` (250–350 lines); (3) `InterfaceField.geometry::Any` forces ~20 hand-written function barriers across the code base.
- Typed policies exist (`CMDGFMProjection`/`MimeticProjection`, transport methods) but are still branched on at runtime in many places (`isa FrozenInterfaceFluxes`, `variant::Symbol`, `GFM.conservative::Bool`, `preconditioner::Symbol`).
- Layout vs. include order: `indicator/` mixes interface reconstruction, embedded-solid operators, VOF transport and visualization geometry; policy types for transport live in three files across two directories; `variable_diffusion_*` and the projection code sit in `two_phase/` although they are generic / shared.
- Docs: exports are almost fully documented (only `MimeticProjectionSolver` lacks a docstring); the weak spots are non-exported-but-central structs (`TwoPhaseModel`, `TwoPhaseFlowWorkspace`, `VariableStaggeredDiffusionSolver`), misleading stats fields, and error messages that name pre-refactor keywords.

## 3. Details for high / med findings

### F1 – Mimetic projection per-step rebuild (high)
```julia
# mimetic_projection.jl:842-862 (every step)
data = _mimetic_face_data(solver, workspace)          # 10 fresh Vector{T}
pressure_operator = _mimetic_pressure_operator(solver) # new GradientConstructionCache each call (foundation:170-172)
incidence = _mimetic_incidence(mesh, T)                # triplet -> sparse
active_set = Set(active_faces)
pressure_positive = pressure_operator.stiffness[pressure_indices, pressure_indices]
incidence_pressure = incidence[:, pressure_indices]
...
# project! :1094-1109
solution = zeros(T, …); correction_rhs = copy(rhs)
krylov = Krylov.MinresWorkspace(matrix, correction_rhs)   # inside `for refinement in 1:8`
```
Shape of fix: reuse the existing `CMDGFMPressureCache` machinery, but key the cache on the same topology signature (block keys + geometry revision) already used by `_reconstruction_is_current`. `_cmdgfm_pressure_cache!` (cmdgfm_cache.jl:290-330) is the template; the Mimetic path needs only incidence + pressure operator + `pressure_indices`. Keep `MimeticProjectionWorkspace` fully concrete (it is a good model). Also allocate MINRES once and `Krylov.krylov_solve!`/resize like CMDGFM does (`cmdgfm_projection.jl:930-940`). The joint-fit stage (mimetic_joint_fit.jl:43-111,169-201: `nullspace`, `vcat(...)\vcat(...)`, `Vector{Vector{Int}}`, `Vector{Matrix{T}}` per row per sweep) is the dominant allocation source *[scout]*; it needs patch-local scratch, not caching.

### F2 – shared projection layer (high)
Proposed split of `two_velocity/projection/` (include order top→bottom, no forward references):
```
methods.jl            # policy structs (+ validation of preconditioner)
common.jl             # incidence!, gauge partition, face data, pressure operator, boundary constraints, cell-solution writeback,

mimetic_projection.jl # assembly + MINRES + project!
```

Tests that compare `_mimetic_incidence == _cmdgfm_incidence` become redundant and can be dropped once one function exists.

### F3 – `InterfaceField{T,M,G}` (high)
`InterfaceField` is created in 3 constructors (`interface_field.jl:78,127`, `levelset_initialization.jl:178`, `polygon_initialization.jl:160`) and `Base.copy`; `GeometryField` wraps `solid::InterfaceField` with `geometry === nothing` (`embedded_geometry.jl:42-55`), so `G` is `Nothing` there. Because `InterfaceField{T,M}` is the common annotation and still matches, the migration is mostly: add `G` to the struct, to the `InterfaceField{T,M}(…)` inner-constructor call (line ~108), and delete barrier pairs one by one (`velocity_fields.jl:30-35`, `transport_geometry.jl:94-195`, `vof_fluxes.jl:164-178`, …). Same for `WYAdvectionWorkspace.geometry::Any` (can be dropped entirely: it duplicates `field.geometry`, compare `vof_workspace.jl:115`).

### F4 – diffusion duplication (high)
`variable_diffusion_*` = 1 983 lines (geometry 790, operator 473, preconditioner 359, solver 361). The *discretisation* (E'WE with log-mean viscosity, shear patches) is genuinely new; the surrounding machinery is not. Verified duplicates: hierarchy-reuse state machine (`reused_new_start`, `reused_old_start`, `_matching_tree_level`, level-capping/pruning), residual-norm/roundoff-floor/reliable-Krylov sequence, matrix shift `M + dt/2·K` with a per-column linear diagonal search *[scout]*, and the `stiffness_pointers/…offsets` refresh. Extract these three pieces to `src/solvers/` and `src/operators/` and pass callbacks. Note a larger unification with `StaggeredDiffusionOperator` would change single-phase numerics (different discretisation) and is **not** mechanical **[INFERENCE]**. Also quadratic setup cost *[scout]*: `_stiffness_refresh_map!` linearly scans each sparse column per stress pair (`variable_diffusion_geometry.jl:167-173`) then `sortperm` (186); `_sparse_pointer_lookup` (`solvers/multigrid/hierarchy.jl:294-303`) already exists.
