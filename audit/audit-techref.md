# Audit `techref`: technical-reference docs vs implementation

Scope: `docs/src/{two-phase-flow,two-velocity-advection,staggered-advection,pressure-gradient,poisson,navier-stokes,shared-memory-parallelism,adaptive-refinement,literature-todos,architecture}.md` against `src/`, `test/`, and (for the "Proposed technical reference" part) the thesis sources in `/home/ronald/Documents/phd_project/thesis/*.tex`.
Method: static reading and grep only; nothing was run or compiled. Items not observed are marked **[INFERENCE]**. No derivation was re-done in full; items flagged "for derivation-checker" need a follow-up.

## 1. Summary

1. The docs are mostly *accurate where they state a formula*: LW face state, all five limiters, geometric viscosity mean, mass-weighted equivalent velocity, two-phase midpoint diffusion RHS, projection signs/tolerance, CMDGFM β formula, MC-limited prolongation and the interpolation-error AMR indicator all match the code line by line.
2. The docs are **not reproducible as a method description**: surface tension (CSF/CGFM/GFM), gravity, height-function curvature, cut-cell/embedded operators, the default mimetic projection (`:joint_smoothed` local fit), time-step limits (formulas, defaults, hard errors), overall temporal order, inflow/outflow BCs and tree-GMG smoother/prolongation have no equations at all.
3. Confirmed doc↔code mismatches: "incremental pressure-correction" (the projection is non-incremental); mimetic active-face rule (mass fraction 1e-6, aperture, embedded-cell exclusion vs "`fraction_floor`"); "every non-periodic side is impermeable" (Inflow/Outflow exist and are untested in docs); the two wave-convergence tables (navier-stokes.md, poisson.md) cannot be reproduced from `test/` (tests only assert thresholds); equation cross-reference "(5)" in two-velocity-advection.md is wrong.
4. Thesis deviations that the docs never state: CMDGFM β (code: diagonal-dominance formula; thesis: β(x)=3x²−2x³), mimetic operator (code: (p,ξ,λ) KKT with local fits; thesis: (p,ψ_η,ψ_τ) potentials), directional-split WY/LW (thesis: unsplit donating regions), no parabolic/MOF reconstruction, no centroid advection, no aperture surface tension (AST), gravity step limit √2 stricter than thesis eq. (pt2:overview:grav_timestep).
5. Recommendation: move all derivation-level content into a LaTeX technical reference in thesis notation (outline in §5) and reduce the Documenter explanation pages to short summaries with stable links; see §5.4 for build/hosting.

## 4. Details, verified items, not checked, nits

### 4.1 Details for high findings

**F1 (time integration).** Code order (`single_phase/stepping.jl:84-110`): copy `old_velocity` → boundary → `_transport_substep!` (LW sweeps, frozen transporting flux `old_velocity`) → `_body_force_substep!` at `t+dt/2` → boundary → `_diffusion_substep!` → boundary → `_refresh_pressure_substep!` → `_phase_force_substep!` (σ, then gravity, added to the *velocity*, after diffusion) → one `project!`. This matches the prose of navier-stokes.md "Common step". What is missing is (i) the statement that `project!` solves `−D κ̂ G p = −D u/Δt` for the **whole** `p` (no `∇p^n` in the predictor: non-incremental; `p` is a projection pressure, with O(Δt) boundary-layer error at no-slip walls; the doc's own Brown–Cortez–Minion citation is about exactly this), (ii) that the single-phase explicit half of Crank–Nicolson uses `L u^n` whereas the two-phase/two-velocity half uses `K u*` (post-transport state) — the former is an unsplit scheme, the latter a Lie splitting; the thesis (`pt2:diffusion:stress_tensor`) corresponds to the latter, (iii) in the two-phase path ρ and μ are evaluated at the **new** interface (after WY transport) for the entire diffusion substep, (iv) the pressure returned excludes the capillary jump (σ enters as an acceleration `a_σ` on the predictor, equivalent by linearity to thesis `ζ∇χ` in the gradient operator, `pt2:overview` eq. for `\sgrad{}`) **[INFERENCE: not checked what `flow.pressure` is used for in diagnostics]**.
*For derivation-checker:* formal temporal order of the single-phase scheme. Taylor expansion with cross term `−C'(u)Lu` suggests that the unsplit explicit-advection/CN combination is only first order for nonlinear advection+viscosity (the missing term is `C'(u)·Lu` in `u''`); TG regressions (where `C(u)` is a gradient) would not expose it.

**F2/F3 (two-velocity projections).** See table. Algebraic check done for F3: with `R=|n_t/n_f|`, `s=γ_lg+γ_gl`, `β=(1−s)/(R−s)` one gets `βR+(1−β)s=1`, so the off-diagonal absolute row sum of the jump row (coefficients `βR·w_k` on transverse jumps, `(β−1)γ` on the two inference-face jumps, from `cmdgfm_projection.jl:593-640`) equals the unit diagonal. Pressure-gradient terms `(β−1)(Ḡ_{h^g}−Ḡ_{h^l})` sit in the (ξ,p) block and are not covered by that dominance statement; the doc says "every row weakly diagonally dominant" without qualifying "of the ξξ block".

**F4 (tables).** Searched `test/` and the repo for `4.70e-4`, `5.20e-3`, `2.38`, `2.73`, `3.67`, `4.84` and for `2.882e-2` etc.: found only in the docs. The test prints errors/rates (`two_phase_waves.jl:242-262`) but asserts only `endpoint_rate ≥ minimum_rate`.

**F5 (BCs).** `enforce_velocity_boundary!(…::VelocityBoundaryConditions)` (`staggered_diffusion.jl:118-190`): Inflow → `f(x,y,t,axis)`, Outflow/ZeroGradient → area-and-aperture weighted average of adjacent interior face values, other sides 0; then, if any `Outflow` side exists, all outflow faces get a uniform correction `−net_flux/outflow_area` so that total boundary flux is exactly zero (needed for the Neumann projection); otherwise a nonzero net flux throws. `ZeroGradientVelocity` has no flux correction.

**F6 (limits).** `stable_timestep(::FaceVelocity, ::StaggeredAdvectionWorkspace)` returns `cfl / max_dual Σ_f|F_f|/V` (sum over *all* dual faces, not only outflow), so for 1-D flow on a uniform mesh `dt = cfl·h/(2|u|)`; the thesis CFL `dt ≤ h/U` is therefore 2× (in 2-D up to 4×) more permissive than this bound with cfl=1. The WY bound is `cfl/max(incoming, outgoing, |u|/h_donor)` with `cfl≤1/2`. Tests: only the gravity bound is asserted (`two_phase_navier_stokes.jl:36-60`); the capillary bound has no test **[checked by grep for `4pi` in test/: none observed]**.

### 4.2 Verified as correct (doc ≡ code, or internally consistent)

- Staggered LW face state, both flux signs, incl. `−Δt/4(q⁻D⁻+q⁺D⁺)`; Courant at AMR connections `|ΔtF_g|/min(W₋,W₊)`.
- All five limiter functions, MC prolongation slope, restriction average (`mesh/transfer.jl`), interp-error indicator, priority rule, coarsen-delay logic head (`_can_coarsen`).
- Density: staggered liquid fraction weights `h_m c_m + h_p c_p` equal the dual-volume weights `αV` on 2:1 faces (coarse α=½ ⇒ 2h_f² : h_f²), so doc and code agree on AMR; viscosity `μ^c μ^{1−c}` computed as `exp(log μ_g + c·Δlog μ)` (affine in c, so interpolate-then-average ≡ average-then-interpolate as `variable_diffusion_geometry.jl:241-243` states).
